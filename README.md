# AllBookTab · 书签整理与新标签页导航

一个 Chrome 扩展插件：自动读取浏览器书签，智能分类整理成新标签页导航站。无需配置、无需登录，装上即用。

## 安装

1. 下载本仓库（或 Release 中的 `allbooktab-v*.zip`）并解压
2. Chrome 地址栏打开 `chrome://extensions/`，右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择 `extension/` 目录（zip 包则直接拖入）
4. 打开新标签页即可

## 功能

### 新标签页导航
- **自动分类**：基于书签「标题 + URL」的通用规则引擎，13 个顶层分类 + 二级子分类，无个人路径依赖，任何人可用
- **多标签体系**：20 个内容类型标签（教程/文档/工具/社区/视频…），一个书签可有多个标签，标签栏多选筛选支持「匹配任意 / 匹配全部」
- **实时搜索**：⌘K 聚焦，按名称/域名即时过滤
- **侧边栏导航**：桌面端两级侧边栏（分类 → 子分类），点击滚动定位、滚动自动高亮；窄屏自动切换为横滑标签条
- **拖拽归类**：不满意的分类直接把卡片拖到侧边栏目标目录；没有合适的就拖到底部「＋新建分类」新建（支持「分类/子分类」格式）；手动归类持久化到 `chrome.storage`，卡片左下角 ↺ 可恢复自动分类
- **快捷入口**：用户自定义（默认为空，上限 12 个），悬停书签卡片点 ☆ 收藏
- **高清 favicon**：三级加载链（favicon.im 128px → DuckDuckGo → 本地 `_favicon`），按域名缓存；canvas 像素分析自动检测白色 Logo 并加深色底衬
- **深色模式**：手动切换 + 跟随系统，记忆偏好
- **书签实时同步**：监听全部 6 个 `chrome.bookmarks` 事件（增/删/改/移动/排序/批量导入），书签一变页面即刷新
- **私密分类**：默认模糊锁定，且不参与标签筛选

### 书签整理（右上角「整理」）
- **重复检测**：按 URL 去参数归一化判重；清理前可先「查看」明细——按组列出每对重复书签，标明保留哪个/删除哪个及所在文件夹路径
- **无效书签**：检测 `chrome://` 等浏览器内部页面；同样支持先查看明细再清理
- **一键整理**：在书签栏生成「整理后的书签」文件夹，按分类归档全部书签
- **导出 HTML**：导出整理后的 Netscape 格式书签文件，可导入任意浏览器

## 文件结构

```
extension/            # Chrome 扩展（主体）
├── manifest.json     # Manifest V3 配置
├── newtab.html       # 新标签页
├── css/newtab.css
├── js/app.js         # 页面逻辑（分类渲染、拖拽、整理面板）
├── js/classifier.js  # 通用分类引擎（标题 + URL 规则）
├── js/popup.js       # 工具栏弹窗
└── icons/

index.html            # 静态导航站成品（早期版本，单文件可直接部署）
gen_nav.py            # 静态版生成脚本（书签更新后重跑）
classify_bookmarks.py # 静态版书签解析/清理/去重/分类脚本
bookmarks_整理后.html # 整理后的 Netscape 格式书签（可导入浏览器）
```

## 说明

- 插件对书签的任何改动（去重、清理、生成整理文件夹）都会有明确提示，且不改动你原有的书签结构（整理结果写入独立的新文件夹）
- 手动分类、快捷入口、主题偏好仅存于本地（`chrome.storage.local`），不上传任何数据
