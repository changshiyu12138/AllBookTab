# My Nav · 个人网址导航站

基于个人浏览器书签（781 个站点）自动生成的单文件网址导航站。

## 功能

- **自动分类**：10 个顶层分类 + 二级子分类，基于书签内容智能归类
- **多标签体系**：20 个内容类型标签（教程/文档/工具/社区/视频…），一个书签可有多个标签
- **标签多选筛选**：跨分类多选标签精准锁定书签，支持「匹配任意 / 匹配全部」两种模式，与侧边栏分类导航并存、与搜索联动
- **实时搜索**：⌘K 聚焦，按名称/域名即时过滤
- **侧边栏导航**：桌面端两级侧边栏（分类 → 子分类），滚动自动高亮；窄屏自动切换为横滑标签条
- **快捷入口**：用户自定义（默认为空，上限 12 个），悬停书签卡片点 ☆ 收藏，localStorage 持久化
- **品牌色 + 真实 Logo**：每张卡片悬浮时使用网站品牌色，图标加载网站 favicon（离线自动回退）
- **深色模式**：手动切换 + 跟随系统，记忆偏好
- **私密分类**：默认模糊锁定，且不参与标签筛选

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 导航站成品（单文件，可直接部署） |
| `gen_nav.py` | 导航站生成脚本（书签更新后重跑） |
| `classify_bookmarks.py` | 书签解析、清理、去重、分类核心逻辑 |
| `bookmarks_raw.txt` | 原始书签文本转储（中间产物） |
| `bookmarks_整理后.html` | 整理后的 Netscape 格式书签（可导入浏览器） |

## 更新流程

1. 浏览器导出书签 HTML，替换源文件路径（`classify_bookmarks.py` 中的 `SRC`）
2. 运行 `python3 classify_bookmarks.py` 重新整理书签
3. 运行 `python3 gen_nav.py` 重新生成导航站
4. 打开 `index.html` 即可使用，或部署到任意静态托管
